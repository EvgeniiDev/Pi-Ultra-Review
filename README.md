# Pi Ultra Review

Плагин для [Pi](https://github.com/earendil-works/pi-coding-agent): параллельное ревью кода сразу несколькими моделями.

## Проблема

Ревью одной моделью — это всегда одна точка зрения. Она может пропустить уязвимость, не заметить проблему с производительностью или просто ошибиться. А гонять код по моделям по очереди — долго.

## Решение

Плагин отправляет ваш диф на ревью **сразу нескольким моделям одновременно** — каждая смотрит код со своей стороны (безопасность, корректность, производительность, поддерживаемость, стиль, best practices). Все ревью собираются в один отчёт с итоговым вердиктом.

## Как пользоваться

- В Pi: команда `/ultra-review` — мастер: выбираете скоуп (что ревьюить), направления и модели
- Или инструмент `ultra_review` с параметрами `scopeId`, `specIds`, `modelIds`, `deep`

Отчёт сохраняется в `reviews/`.
